# 🛒 E-Commerce Sales Analysis — Power BI

## 📊 Project Overview

This project presents an interactive E-Commerce Sales Analysis Dashboard created using Microsoft Power BI.

The dashboard analyzes sales performance, profit, quantity, average order value, payment methods, product categories, sub-categories, states, and customer-level sales.

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

### Sales & Profit Analysis
- Monthly profit trends
- Profit by sub-category
- Sales amount by state
- Customer-wise sales analysis

### Product Analysis
- Quantity by product category
- Profit contribution by sub-category

### Payment Analysis
- Quantity distribution by payment mode

### Interactive Filters
- Quarter
- State

## 📊 Dashboard Features

The dashboard provides interactive visualizations to analyze:

- Monthly Profit Trends
- Profit by Sub-Category
- Quantity by Category
- Quantity by Payment Mode
- Sales Amount by State
- Customer-wise Sales
- Overall Sales, Quantity, Profit and AOV KPIs

1. Download the `ECommerce.pbix` file.

3. Use the available filters and visualizations to explore the data.
4. Interact with the dashboard to analyze sales and profit performance.
